Добро пожаловать в Custom Field Editor  
(aka «CFE – тот самый плагин, который даёт приделать поля куда угодно»)

================================================================================
Что тут вообще происходит?
--------------------------------------------------------------------------------
•  Бек-энд – обычный WordPress-плагин на PHP.  
•  Фронт – React-приложение.  
  Оно лежит в `react-app/`, а собранные бандлы автоматом летят в `assets/`.  
•  Всё болтает между собой через кастомный REST-namespace `/cfe/v1/*`.  

================================================================================
Быстрый старт для разработчика
--------------------------------------------------------------------------------
1. `git clone … && cd react-app && npm i`  
2. `npm run dev` – откроется Vite-сервер с горячей перезагрузкой (порт 5173).  
3. В WP-админке активируешь плагин → появится пункт меню «CFE».  
4. Готово: правишь React-файлы, пересобираешь сборку, страница сама обновляется.  

Production?  
`npm run build` → получаются `app.js` + `app.css` в `assets/js/admin/`.  
Версионируются по `filemtime()`, так что кэш сразу сбрасывается.

REST-шпаргалка (используется фронтом)
--------------------------------------------------------------------------------
GET    `/cfe/v1/field-groups`             – все группы  
POST   `/cfe/v1/create-post-group`        – создать новую  
GET    `/cfe/v1/field-group/{id}`         – данные одной группы  
PATCH  `/cfe/v1/field-group/{id}/status`  – сменить статус (publish/draft/…)  
GET/POST `/cfe/v1/settings`               – колонки таблицы  
GET    `/cfe/v1/pages`  | `/posts`        – справочники страниц / записей  

Nonce и url-ы фронт получает из `window.cfeSettings` (см. `enqueue-admin.php`).

================================================================================
Файлы React, о которых стоит помнить
--------------------------------------------------------------------------------
components/
  • TopMain               – кнопки «Создать группу», «Настройки таблицы»  
  • GroupTable            – список групп + чек-боксы  
  • FieldTable            – список полей внутри группы (expand-row)  
  • ToggleSwitch / InputText / LineareSelect – базовые UI-кирпичи  

pages/
  • GroupField            – корневой экран со списком групп  
  • SettingsGroup         – форма настроек конкретной группы  

Всё роутится вручную (без `react-router`) через `ExtraPanel.jsx` + `useLocation()`.

FAQ вполоборота
--------------------------------------------------------------------------------
«Почему нет `react-router`?»  
– Нам не нужен полноценный роутинг, достаточно слушать `location.pathname`.

«Где лежат SVG?»  
– Почти все inline прямо в компонентах; в комментариях они свёрнуты «/* … */».

«Как добавить новый тип поля?»  
1) В `TypeFieldSelect` + `IconTextType` добавь пункт.  
2) На сервере придумай схему хранения в `post_content`.  
3) При желании сделай отдельный REST-endpoint.
